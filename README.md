# Portfólio — Alexandre Gomes de Araújo

Site pessoal estático em português, hospedado no GitHub Pages em https://algomjo.github.io/.

## Conteúdo e manutenção

- `index.html`: apresentação, projetos, trajetória e contato.
- `styles.css`: identidade visual e adaptações para celular.
- `favicon.svg`: ícone do site.
- `.nojekyll`: publicação direta dos arquivos estáticos.

Edite os arquivos e envie as alterações para `main`. O GitHub Pages publica a raiz dessa branch automaticamente. Não requer instalação ou compilação. Abra `index.html` em um navegador para uma prévia local.

## Fontes

Os projetos são apresentados como portfólio, com links para seus códigos e para a demonstração já publicada. O site não executa os backends dos projetos.
